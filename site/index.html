Prototype — Hokkien text is a draft, and the voice is a stand-in. Hokkien now has its own colloquial script rather than shared written Chinese, and real Singapore Hokkien narration exists in this repo (MERaLiON, run locally). Until those clips are rendered into site/audio/, Play falls back to reading the Mandarin version in your browser's voice. Teochew has no real voice at all yet. No script here has been through the human accuracy check the problem statement requires, and no native Hokkien speaker has reviewed the dialect text.

Sources — the whitelist

    The crawler reads these and nothing else. Every explainer cites the page it came from. In this prototype those links land on each source's home page — a fabricated deep link would be worse than an honest one.

    Institutions are referred to through one source only. Whether the firm or representative selling to you is licensed is the single checkable fact about a specific commercial offer, so every explainer ends on it and links to the MAS Financial Institutions Directory — never a company site, never another list. A firm absent from the directory is reported as not found there, which is not a verdict either way.
